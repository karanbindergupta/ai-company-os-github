# GROWTH LOOP DESIGN
Campaigns stop when spend stops. **Loops compound.** Search for the loop before funding a campaign.

## Loop shapes
**Referral / viral**
`USER → VALUE → SHARING → NEW USER → VALUE → SHARING`
Test: would a user share this *without* an incentive? If not, you have a promotion.

**Content / SEO**
`CONTENT → DISCOVERY → PRODUCT → DATA → BETTER CONTENT → MORE DISCOVERY`
The data step is what makes it compound. Without it, this is just publishing.

**Product-led**
`USER → CREATES ARTIFACT → SHARED WITH NON-USER → NON-USER SEES VALUE → SIGNS UP`
Strongest loop: the product's normal use generates exposure.

**Network effect**
`MORE USERS → MORE VALUE PER USER → LOWER CHURN + MORE REFERRAL → MORE USERS`
Verify the value genuinely increases with users — most claimed network effects are not.

## Evaluating a loop
| Question | Why |
|---|---|
| What is the **cycle time**? | A 6-month loop barely compounds |
| What is the **amplification factor**? | Below 1.0 it decays; it is not a loop |
| Where does it **leak**? | Every step loses users — which loses most? |
| What makes it **stop**? | Saturation, fatigue, platform dependency |
| Is it **defensible**? | Can a competitor copy the loop directly? |

## Honest assessment
Most products do not have a strong loop, and claiming one that does not exist misallocates the
entire growth budget. **"No compounding loop identified; growth will be spend-dependent"** is a
legitimate, valuable finding — report it plainly to the CEO and CFO, because it changes the
business model.
