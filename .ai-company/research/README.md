# Research memory

| Directory | Holds |
|---|---|
| `sources/` | Source register — every URL, publisher, tier, retrieval date |
| `evidence/` | Individual evidence records, one per material claim |
| `reports/` | Completed research reports with confidence assessments |
| `market/` `competitors/` `customers/` `technology/` `finance/` `regulatory/` `risks/` | Domain research, refreshable independently |
| `decisions/` | Research that fed a specific decision, kept with it |

Every report preserves sources, URLs, dates, conclusions, confidence, assumptions and unresolved
questions, so any finding can be re-verified or refreshed without redoing the work.
